# 💱 Currency Converter

A simple and interactive **Currency Converter** built using HTML, CSS, and JavaScript. It allows users to select currencies, enter an amount, and instantly view the converted value using live exchange rates.

## ✨ Features

* 🌍 Supports multiple currencies
* 💱 Converts between different currencies
* 🔄 Fetches exchange rates dynamically using an API
* 🏳️ Displays country flags for selected currencies
* 🔢 Accepts custom amounts
* ⚡ Updates conversion results instantly
* 📱 Clean and responsive user interface

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and DOM manipulation
* **Fetch API** — Retrieving exchange rates
* **Currency API** — Live currency exchange data
* **Flags API** — Currency/country flag images

## 📸 How It Works

1. Enter the amount you want to convert.
2. Select the currency you are converting **from**.
3. Select the currency you are converting **to**.
4. Click the **Convert** button.
5. The application fetches the latest exchange rate and displays the converted amount.
